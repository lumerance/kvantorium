# Посредник для помощника (GigaChat в Cloud.ru)

Сайт статический (GitHub Pages), поэтому ключ Cloud.ru нельзя хранить в его коде — его увидит любой.
Ключ хранится в маленькой облачной функции `assistant-function.js`, а сайт отправляет вопросы ей.

Функция:
- пускает только педагогов, вошедших на сайт через Яндекс ID и перечисленных в `ALLOWED_LOGINS`;
- ограничивает размер запроса и число запросов в день на педагога (`DAILY_LIMIT`);
- выбирает режим: вопросы по данным — точно и коротко (temperature 0,1), творческие — свободнее (0,7);
- отправляет запрос модели `ai-sage/GigaChat3.5-432B-A28B` в Cloud.ru и возвращает ответ.

## Как создать (Yandex Cloud Functions, ~15 минут)

1. Зайдите в консоль Yandex Cloud (console.yandex.cloud) с вашим Яндекс ID, создайте платёжный аккаунт,
   если его ещё нет. Бесплатного объёма функций (1 млн вызовов в месяц) с запасом хватает.
2. **Cloud Functions → Создать функцию**, имя например `kvantorium-assistant`.
3. Среда выполнения — **Node.js 18** (или новее). Способ — «Редактор кода», файл `index.js`.
   Вставьте содержимое `assistant-function.js` целиком. Точка входа — `index.handler`.
4. Параметры: таймаут **60 секунд** (творческие ответы идут до ~20 с), память 128 МБ.
5. **Переменные окружения:**

   | Имя | Значение |
   |---|---|
   | `CLOUDRU_API_KEY` | API-ключ сервисного аккаунта Cloud.ru (роль `ml_inference_ai_marketplace.apikey-limit.user`) |
   | `ALLOWED_LOGINS` | ваш логин Яндекса (то, что до `@yandex.ru`); несколько — через запятую |
   | `ALLOWED_ORIGIN` | адрес сайта без пути, например `https://lumerance.github.io` |
   | `DAILY_LIMIT` | необязательно, по умолчанию 150 запросов в сутки на педагога |

   Ключ лучше положить в **Lockbox** (секреты Yandex Cloud) и подключить к функции как переменную —
   тогда он не виден даже в настройках функции. Для начала можно и обычной переменной.
6. Создайте версию функции. На вкладке «Обзор» включите **«Публичная функция»** — иначе сайт не сможет
   её вызвать (вход всё равно проверяется по Яндекс ID и `ALLOWED_LOGINS`).
7. Скопируйте ссылку вида `https://functions.yandexcloud.net/d4e…` и впишите её в `js/config.js`
   (`ASSISTANT_URL`) — тогда помощник работает у всех педагогов сразу, никому ничего вставлять не нужно.
   Адрес не секретный: без логина в `ALLOWED_LOGINS` функция отказывает. Новых педагогов добавляйте
   в `ALLOWED_LOGINS` через запятую (Яндекс-логин, без @yandex.ru).
   Для проверки без правки кода адрес можно вписать у себя: **Помощник → Настройка**.

## Расходы

GigaChat3.5-432B-A28B: 96,22 ₽ за 1 млн входящих и 288,6 ₽ за 1 млн генерируемых токенов.
Вопрос по данным ≈ 0,12 ₽, творческий запрос ≈ 0,05–0,25 ₽; при 100 вопросах и 40 творческих
запросах в месяц — около 17 ₽ на педагога. Сайт показывает расход на странице «Помощник».

Защита бюджета: в Cloud.ru у API-ключа можно задать лимит расходов — поставьте, например, 300 ₽ в месяц.
